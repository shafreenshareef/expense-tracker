# Expense Tracker

A simple expense tracker built with Python and SQLite.

## What it does

- Add an expense (amount, category, date)
- View all expenses
- Show the total spent and the total per category

## Plan

1. Command-line app in Python
2. Store the data in a SQLite database
3. Turn it into an API with FastAPI, with login

## Tech

- Python
- SQLite
- FastAPI (planned)

## Status

In progress. Currently building the basic menu.
